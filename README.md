Store Organizer - نموذج سريع لمتجر أدوات تنظيف سيارات

ما يوجد هنا:
- `index.html` — واجهة المستخدم (HTML/JS) عمل محلي.
- `app.js` — منطق التطبيق: إدارة المنتجات، تسجيل وارد/صادر، وجدولة التذكيرات.
- `styles.css` — أنماط بسيطة.

تشغيل محليًا:
- افتح الملف مباشرة (انقر مزدوج أو من PowerShell):

```powershell
Start-Process "C:\Users\Shathan\Desktop\store-organizer\index.html"
```

- أو شغّل سيرفر محلي داخل المجلد:

```powershell
cd "C:\Users\Shathan\Desktop\store-organizer"
python -m http.server 8000
# ثم افتح: http://localhost:8000
```

وظائف سريعة:
- إضافة منتجات مع كمية وسعر.
- تسجيل حركات وارد/صادر وتحديث الكميات تلقائياً.
- جدولة تذكيرات للدفع/الحساب.
- تصدير CSV وJSON واستيراد JSON.

تحسينات مضافة في هذه النسخة:
- حقول جديدة عند إضافة المنتج: `فئة` و`المورد` و`حد إعادة التوريد`.
- عند إدخال كمية ابتدائية للمنتج يتم تسجيل حركة `وارد` تلقائياً للأرشفة.
- النظام يمنع تسجيل حركة `صادر` تؤدي إلى كمية سالبة (ستظهر رسالة خطأ).
- المنتجات التي وصلت إلى حد إعادة التوريد تُبرز كـ "منخفضة المخزون".

الخطوات التالية التي أقترحها:
- إذا أردت مشاركة/تزامن بين أجهزة: أنقل التخزين إلى Supabase (سأعطيك ملفات التهيئة لتضع مفاتيح Supabase). 
- إضافة مصادقة مستخدمين وتقارير مبيعات.
 
التجربة الآن:
- افتح الواجهة، أضف منتجًا مع كمية أولية لرؤية كيف تُسجل حركة الوارد تلقائياً.
- استخدم سجلات المخزون لتسجِّل عمليات وارد/صادر — سيتم منع العمليات التي تُنشئ رصيدًا سالبًا.

أخبرني إذا أريدت أن أفتح الملف لك الآن أو أضيف ميزة محددة (بحث أسرع عن المنتجات، أم إعداد تقارير، أو إرسال تذكيرات بالبريد).
